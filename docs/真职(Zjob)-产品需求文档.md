## 一、产品概述

### 1.1 产品定位

真职（Zjob）是一款面向求职者及其家属的公司信息查询与评估工具。产品整合企业基本面、薪酬竞争力、福利保障、工作节奏、成长与制度、真实口碑六大维度的公开信息，帮助求职者在入职前对目标公司形成"表里如一"的认知，做出更理性的职业选择。

### 1.2 产品愿景

填补市面上工具"只给1-2个维度、无人做整合"的空白，通过**六维交叉验证**机制，让求职者不再只看岗位薪资或单一口碑评价，而是获得一份完整的公司"体检报告"。

### 1.3 核心价值

- **整合性**：Boss直聘只给岗位薪资，看准只给口碑，脉脉只有匿名吐槽——真职将六大维度整合到一处。
- **交叉验证**：薪资百分位 × 加班强度 = 真实时薪；500强趋势 × 真实口碑 = 表里两张皮；晋升路径 × 赛道潜力 = 3年后的自己。
- **差异化**：真实口碑维度（在职/离职员工评价）是公开信息最难获取的部分，也是真职最有机会做深做透的市面空白。

## 二、背景与问题

### 2.1 行业痛点

当前求职者在评估目标公司时，面临三大问题：

1. **信息碎片化**：企业信息散落在企查查、脉脉、小红书、看准、Boss直聘等多个平台，求职者需逐一搜索整合，效率极低。
2. **维度单一**：现有工具各做一两个维度，无人整合——Boss直聘=岗位薪资，看准=口碑评价，脉脉=匿名吐槽。
3. **真实口碑缺失**：HR展示的是"橱窗"，在职/离职员工展示的是"厨房"，但公开渠道难以获取真实的内部视角。

### 2.2 业务背景

- 当前使用方为内部销售团队，用于向待就业青年及其家长展示即将入职的公司信息，需通俗易懂。
- 产品先以内部工具形式使用，未来将向C端开放。
- 初期以Demo形式验证，覆盖少量熟悉公司（如Zara、欧莱雅、蔻驰、罗兰贝格、商汤、米哈游、哔哩哔哩、博世等）。

## 三、用户角色与使用场景

### 3.1 用户角色

| 角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| 内部销售员（B端） | 使用真职向客户/求职者展示公司信息的内部人员 | 快速查询、清晰展示、通俗易懂 |

### 3.2 核心使用场景

| 场景 | 描述 |
| --- | --- |
| **求职前调研** | 求职者用六维度对公司做"体检报告"，红绿灯预警 |
| **面试中追问** | 针对弱项维度追问HR/面试官，交叉验证 |
| **Offer比较** | 多家公司横向打分，量化决策 |
| **销售展示** | 销售员向求职者家长展示公司信息，建立信任 |
| **入职后跟踪** | 持续跟踪公司变化，作为跳槽时机判断依据 |

## 四、产品形态与分发

### 4.1 产品形态

| 阶段 | 形态 | 说明 |
| --- | --- | --- |
| Phase 1（当前） | Web页面 + 搜索框 | 快速验证，与参考链接形式一致 |
| Phase 2 | 小程序 | 内置应用，可生成二维码分享 |
| Phase 3 | 多端同步 | 小程序 + Web + 内置应用（飞书/企业微信） |

### 4.2 分发策略

- **Phase 1**：内部使用，Web链接形式，无需复杂UI。
- **Phase 2**：以内部人工具方式使用，先做到自己用得顺手，未来开放C端端口。
- **Phase 3**：从B转C，省去中间环节，直接面向求职者投放。

### 5.2 功能模块详细说明

#### 5.2.1 公司搜索与查询

| 需求项 | 说明 | 优先级 |
| --- | --- | --- |
| 公司搜索 | 支持按公司名称关键词搜索，返回匹配的公司列表 | P0 |

#### 5.2.2 六维度信息展示

产品核心功能，对每家公司按以下六大维度展示完整信息：

**维度一：企业基本面**

> 一句话：这家公司"多大、多稳、多强"
>
> 决策意义：判断公司处于"上升期/平台期/衰退期"，决定你的职业是顺风还是逆风。

| 评估项 | 判断点 | 决策意义 |
| --- | --- | --- |
| 企业规模 | 人数/营收量级 → 大厂/中厂/小厂/创业公司 | 决定平台资源与稳定性 |
| 是否上市 | 股票代码 → 上市公司信息透明度更高 | 信息可查性差异巨大 |
| 500强排名 | 世界500强/中国500强近5年排名趋势 | 上升=景气；下降=预警 |
| 行业地位 | 细分领域排名、是否"最佳雇主" | 行业地位+雇主品牌 |

**维度二：薪酬竞争力**

> 一句话：给的钱在行业里算什么水平
>
> 决策意义：不只看数字，看"性价比"——同岗行业百分位低的公司，说明它在压榨。

| 评估项 | 判断点 | 决策意义 |
| --- | --- | --- |
| 真实薪资水平 | 实发到手 vs offer数字 | 是否有"画饼"成分 |
| 薪资结构 | base/绩效/年终/期权各占比 | 固定占比越高越稳定 |
| 行业百分位 | 同岗位薪资在行业内的百分位（P75/P50/P25） | P75=有竞争力；P25=偏低 |
| 离职补偿规则 | N+1/2N/竞业限制范围与补偿 | 退出时的安全垫 |

**维度三：福利保障**

> 一句话：除了工资还给你什么
>
> 决策意义：福利是"隐性薪资"，规范的公司这块能多出10-20%的实际收入感。

| 评估项 | 判断点 | 决策意义 |
| --- | --- | --- |
| 五险一金 | 基数与比例：按实际工资全额=规范；按最低基数=缩水 | 影响退休/购房/医疗 |
| 商业保险 | 医疗/意外/补充保险，是否覆盖家属 | 保障深度 |
| 假期体系 | 法定+福利年假/病假/产假天数 | 休息权落实程度 |
| 节日礼品/补贴 | 餐补/交通补/通讯补/节日费（现金 or 实物） | 隐性收入 |

**维度四：工作节奏**

> 一句话：用命换钱还是用钱换命
>
> 决策意义：月薪3万+996 ≈ 月薪2万+965，时薪才是真实薪资。

| 评估项 | 判断点 | 决策意义 |
| --- | --- | --- |
| 加班强度 | 月均加班时长、是否996/大小周 | 量化数据优先 |
| 加班文化 | 主动/被动、领导是否以身作则 | "内卷程度" |
| 加班补偿 | 加班费/调休/无补偿 | 有无补偿差别巨大 |
| 下班后打扰 | 下班后/周末工作消息频率 | WLB真实感受 |

**维度五：成长与制度**

> 一句话：进去之后能长多大本事
>
> 决策意义：前几份工作，成长性 > 薪资。3年后你是行业抢手货还是被锁死在旧岗位，差别在此。

| 评估项 | 判断点 | 决策意义 |
| --- | --- | --- |
| 晋升路径 | 几年一评/晋升率/有章可循 vs 领导说了算 | 成长可预期性 |
| 培训体系 | 入职/在职/导师制/学费报销 | 制度化培养 vs 自生自灭 |
| 内部流动性 | 转岗机制、跨部门机会 | 赛道切换可能性 |
| 赛道潜力 | 行业增速、政策导向、AI替代风险 | 顺势 vs 逆势 |

**维度六：真实口碑**

> 一句话：里面的人怎么说（公开信息查不到的核心）
>
> 决策意义：HR展示的是"橱窗"，在职/离职员工展示的是"厨房"。这是市面工具最缺、真职最有机会做差异化的维度。

| 评估项 | 判断点 | 决策意义 |
| --- | --- | --- |
| 在职员工评价 | 脉脉/看准/LinkedIn | 橱窗视角 |
| 离职员工评价 | 匿名区/知乎/小红书 | 厨房视角（说真话） |
| 离职率 | 年化离职率、核心岗位稳定性 | 高离职率=红色警报 |
| 负面事件 | 裁员/欠薪/劳动仲裁记录 | 风险底线 |

## 六、数据需求

### 6.1 数据来源

| 数据维度 | 主要数据源 | 采集方式 |
| --- | --- | --- |
| 企业基本面 | 企查查、天眼查、公司年报、公开财报 | 爬虫 / API |
| 薪酬竞争力 | Boss直聘、看准、招聘网站 | 爬虫 |
| 福利保障 | 公司官网、招聘JD、员工反馈 | 爬虫 + 人工 |
| 工作节奏 | 脉脉、看准、小红书 | 爬虫 |
| 成长与制度 | 公司官网、招聘JD、脉脉 | 爬虫 + 人工 |
| 真实口碑 | 脉脉、看准、知乎、小红书、LinkedIn | 爬虫 |

### 6.2 数据采集方案

**方案一：爬虫采集（Phase 1 优先）**

- 优势：成本低、覆盖面广
- 风险：法律合规问题、反爬限制
- 适用：内部使用阶段

**方案二：购买数据（Phase 3 考虑）**

- 优势：合规、稳定、数据质量高
- 劣势：成本较高
- 适用：C端开放后

**补充方案：人脉资源补充**

- 通过熟悉的HRD/市场部朋友获取一手信息
- 适用于Demo阶段的少量公司

### 6.3 数据展示原则

- 财报数据不全部堆砌，通过同比/环比得出结论性展示
- 薪资以行业百分位形式展示（P75/P50/P25）
- 口碑信息需标注来源和时效性
- 缺失数据明确标注"暂无数据"，不编造

## 十、附录

### 10.1 六维度框架差异化价值

**市面工具通病：** Boss直聘=岗位薪资、看准=口碑评价、脉脉=匿名吐槽——各做一两个维度，无人整合。

**真职3大交叉验证：**

1. 薪资百分位 + 加班强度 → 算出真实时薪
2. 500强排名趋势 + 真实口碑 → 看到"表里两张皮"
3. 晋升路径 + 赛道潜力 → 判断3年后的自己

**最核心差异化：** "真实口碑"维度——公开信息难获取，真职有机会做深做透，这是市面空白。

### 10.2 术语表

| 术语 | 说明 |
| --- | --- |
| 六维交叉验证 | 将六大维度的信息两两交叉比对，得出更深层洞察的分析方法 |
| 红绿灯预警 | 对每个维度按绿（良好）/黄（关注）/红（预警）进行标记 |
| 橱窗视角 | HR/官方展示的信息，偏向正面 |
| 厨房视角 | 在职/离职员工的真实评价，更接近真相 |
| 行业百分位 | 同岗位薪资在行业内的排名位置，P75表示高于75%的同岗位 |
